# MG Serras

Landing page para apresentar a serraria movel e encaminhar interessados ao WhatsApp.

## Requisitos

- Node.js 20 ou superior
- npm

## Desenvolvimento

```bash
npm install
npm run dev
```

Acesse http://localhost:3000. Para verificar a versao de producao, execute `npm run build`. A configuracao atual gera uma exportacao estatica na pasta `out`.

## Organizacao

- `app/`: pagina, metadados e estilos globais.
- `components/layout/`: cabecalho e rodape.
- `components/sections/`: secoes da landing page.
- `config/site.ts`: contato, redes sociais e perguntas frequentes.

O numero de WhatsApp deve ser conferido com o responsavel antes da divulgacao. As fotografias atuais sao ilustrativas; substitua por imagens autorizadas da maquina e do trabalho real. Especificacoes, prazos e regioes de entrega devem ser confirmados antes de serem incluidos.
